# Calculator

A clean, responsive calculator built with **HTML, CSS, and vanilla JavaScript**. It provides a simple button-based interface for everyday arithmetic, with keyboard support and light/dark appearance support.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Percentage calculation
- Positive/negative sign toggle
- Clear (AC) button
- Decimal number support
- Keyboard input for faster calculations
- Responsive layout for desktop and mobile screens
- Light and dark color schemes, including system preference support
- Handles division by zero by displaying an error

## Built With

- **HTML5** — calculator structure
- **CSS3** — layout, styling, responsive design, and color themes
- **JavaScript** — calculator operations and keyboard interactions

## Getting Started

No installation, packages, or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/HafizHassanAlee/calculator.git
   ```

2. Open the project folder:

   ```bash
   cd calculator
   ```

3. Open `index.html` in your web browser.

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0–9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `.` | Decimal point |
| `Enter` or `=` | Calculate result |
| `%` | Percentage |
| `Backspace` | Delete the last digit |
| `Escape` or `Delete` | Clear the calculator |

## Run Locally

You can run this project directly in your browser by opening `index.html`. For a local development server, use the Live Server extension in Visual Studio Code.
